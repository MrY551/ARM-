### 3.3 Apache `conf/httpd.conf`

```
Define SRVROOT "<原来的开发机路径>"
```

## 4. 安装/运行行为

1. **安装路径规则**（压缩包内两份说明一致）：
   - 不能含中文或空格，否则报 `Can't change dir to '<path>'`；
   - 路径必须纯净，不能有已安装的 V8，重装须换路径。
2. 安装器把 `app/` 整棵树释放到目标目录，注册表记录安装位置与卸载信息，创建开始菜单/桌面快捷方式，安装为 Windows 服务 `phpstudy服务`（本机可见 `phpStudySrv` 正在运行）。
3. 面板首次启动时把 `httpd.conf`/`nginx.conf`/`php.ini`/`my.ini` 里的开发机路径改写为真实安装路径，并按用户操作生成 `conf/vhosts/*.conf`。
4. 端口管理：面板读取 `netstat` 输出（`phpStudyCore.dll` 内含 `\s*TCP\s+\d+\.\d+\.\d+\.\d+:(\d+)\s+...LISTENING\s+(\d+)` 正则与 `| findstr "LISTENING"`），据此判断端口占用；`slot_checkPortAndService()` 是端口/服务检查入口。
5. 升级：`update.exe` + `xp.cn` 系列接口（`https://www.xp.cn/index/workerorder/...`、`bug_collect`）。

## 5. 移植到银河麒麟 ARM64 的映射

| Windows 版 | 麒麟版实现 | 说明 |
|---|---|---|
| Inno Setup 安装器 | 自解压 `.run`（bash+tar.gz）+ `.deb` | 同一套规则校验 |
| `app/COM/phpstudy_pro.exe`（Qt 面板） | `phpstudy` 控制台 | 面板按钮 → 子命令，见下表 |
| `app/Extensions/Nginx1.15.11` | `app/Extensions/Nginx1.18.0/`（内置 arm64 二进制 + 自带 loader，独立 conf/logs/temp） | 目录布局与命名保持一致 |
| `app/Extensions/Apache2.4.39` | `app/Extensions/Apache2.4.62/`（内置 arm64 httpd + 118 个模块） | 与 Nginx 二选一（同端口），`phpstudy switch` 切换 |
| `app/Extensions/php/php7.3.4nts`（php-cgi） | `app/Extensions/php/php7.4.33/`（内置 php-fpm，127.0.0.1:9000） | 与 `fastcgi_pass 127.0.0.1:9000` 完全对齐 |
| `app/Extensions/MySQL5.7.26` | `app/Extensions/MySQL10.5.23/`（内置 MariaDB 10.5，独立 datadir/socket/pid） | 5.7 参数保留，MariaDB/8.x 差异项加 `loose-` 前缀 |
| `app/Extensions/FTP0.9.60`（FileZilla） | 不提供 | 麒麟上用系统 vsftpd，不在本包范围 |
| `app/WWW` + `error/*.html` | 同名同义（`index.html` + `index.php` 探针 + 13 个错误页） | 视觉重做为响应式 |
| 注册表/服务 `phpStudySrv` | systemd `phpstudy-{nginx,php,mysql,apache}.service` | 无 systemd 时回退 pid 文件直管 |
| `conf/vhosts/*.conf` 由面板生成 | `phpstudy site add` 生成 | 模板取自 3.2 / 3.4 |
| `Listen.conf` / `default-default.conf` | 保留同名文件（Nginx 侧改为 `conf/listen.port` 纯文本，避免被 nginx 当指令解析） | 见下方差异说明 |

## 6. 移植时发现并修掉的 Windows 版遗留问题

1. `vhosts/Listen.conf` 写的是 `Listen 80`（大写），Nginx 会把它当未知指令 → EOF 语法错误。麒麟版 Nginx 侧不放该文件，端口写在每个 `server{}` 里，另在 `conf/listen.port` 记录纯文本端口供控制台读取。
2. `DocumentRoot`/`SRVROOT`/`my.ini` 里是开发机绝对路径 → 安装即渲染为真实路径，无需首次启动再改写。
3. Apache 不识别非标准状态码 509（`ErrorDocument 509` 会让 `apache2 -t` 直接失败）→ 麒麟版 Apache 只声明标准码，509 交给 Nginx 的 `error_page`。
4. Debian/Ubuntu 的 `mod_log_config.so`、`mod_unixd.so` 编译进核心、没有独立文件 → 安装器按 `.so` 是否存在自动禁用 `LoadModule`，避免 `apache2 -t` 失败。
5. MySQL 8 不接受 `skip-host-cache=ON`（带参数直接启动失败）→ 改为无值写法，并对 8.x 移除/改名的参数统一加 `loose-` 前缀。
6. 原 `my.ini` 的 `default-storage-engine=MyIsam` 在 8.x 仍可用，保留以维持行为一致。

## 6.1 内置组件的取舍

麒麟版把四个组件按 aarch64 打进安装包（来源 Debian 11 bullseye arm64），
每个组件带 `ld-linux-aarch64.so.1` + 全依赖库 + `libc`，启动时走 `--library-path`：

- 不依赖目标机的 nginx/php/mysql 包，也不依赖目标机 glibc 版本（麒麟 V10 SP1 的 2.28 与
  bullseye 包的 2.31 要求冲突，自带 loader 直接绕开这个冲突）；
- 单个组件可整体替换：换 `payload/components/<name>.tar.gz` 后 `./build.sh` 重打包即可；
- 代价是安装包体积（.deb 85 MB / .run 89 MB），解包后约 700 MB。
