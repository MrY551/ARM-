# Xiao Huang 用户手册

版本 0.0.0.1Beta ｜ 适用 银河麒麟 V10 / UOS / openEuler / Debian / Ubuntu（aarch64）

---

## 1. 这是什么

一套装在麒麟上的 Web 运行环境，一个包解决四件事：

- Nginx（或 Apache）跑站点
- PHP-FPM 跑 PHP
- MariaDB 存数据
- vsftpd 传文件

外加一个网页管理面板（`http://127.0.0.1:9002/`）和一套命令行 `xiaohuang`。

所有组件都打在安装包里，**装的时候不联网、不需要系统仓库、不要求机器上装过 nginx/php/mysql**。

装完的目录结构跟 phpStudy V8 一致，老用户不用重新学：

```
/opt/xiaohuang/
├── xiaohuang.ini            配置清单
├── app/
│   ├── WWW/                 站点根目录
│   ├── Extensions/          各组件（Nginx / Apache / php / MySQL / FTP）
│   └── panel/               管理面板
├── bin/xiaohuang            命令行
├── conf/                    站点模板
├── logs/  run/
└── uninstall.sh
```

## 2. 装之前先看这几条

### 2.1 系统要求

| 项目 | 要求 | 怎么查 |
|---|---|---|
| 架构 | aarch64 | `uname -m` 输出 `aarch64` |
| 权限 | root | `id -u` 输出 `0` |
| 初始化系统 | systemd（推荐） | `systemctl --version` |
| glibc | ≥ 2.17 | `ldd --version \| head -1` |
| 磁盘 | 空余 ≥ 1.5 GB | `df -h /opt` |

glibc 版本不用太纠结，组件自带 loader 和 libc，麒麟 V10 SP1 的 2.28、SP2 的 2.31 都能跑。

### 2.2 端口规划

默认占三个端口，被占用了安装器会自动往上找：

| 用途 | 默认 | 被占用时 |
|---|---|---|
| HTTP（Nginx/Apache 共用） | 80 | 8080 |
| MySQL | 3306 | 3307 |
| PHP-FPM | 9000 | 9001 |
| FTP | 21 | 2121 |
| 面板 | 9002 | 9003 |

先确认这些端口没被占用：

```bash
ss -lnt | grep -E ':(80|3306|9000|21|9002) '
```

有输出说明被占了。可以先用 `--http-port 8080` 之类指定，或者装完再改。

### 2.3 安装路径的规矩

路径只能是**纯英文、数字、`._/+@-`**，不能有空格、不能有中文、必须是绝对路径。

```bash
# 合法
/opt/xiaohuang        /data/web/panel        /usr/local/xiaohuang

# 不合法（安装器会直接退出，退出码 2）
/opt/xiao huang       （有空格）
/opt/小黄面板          （有中文）
xiaohuang             （相对路径）
```

这条规矩是从原版 phpStudy 沿用的——路径带空格会让 Nginx/Apache 的配置解析出问题。

## 3. 安装

### 3.1 用 deb（服务器推荐）

```bash
sudo dpkg -i xiaohuang-kylin-arm64_0.0.0.1Beta_arm64.deb
```

装完不会自动启动服务，手动起：

```bash
sudo xiaohuang start
```

默认装到 `/opt/xiaohuang`。想换路径，改 `/etc/xiaohuang/install.conf` 再重装：

```bash
sudo nano /etc/xiaohuang/install.conf
# INSTALL_DIR=/data/xiaohuang
sudo dpkg -P xiaohuang-kylin-arm64
sudo dpkg -i xiaohuang-kylin-arm64_0.0.0.1Beta_arm64.deb
```

> 改完要 `dpkg -P` 卸载再 `dpkg -i` 重装才生效，本包没注册 debconf，`dpkg-reconfigure` 不读这个文件。

### 3.2 用 run（自解压，参数最全）

```bash
chmod +x xiaohuang-kylin-arm64-0.0.0.1Beta.run
sudo ./xiaohuang-kylin-arm64-0.0.0.1Beta.run
```

常用组合：

```bash
# 装到指定目录并立刻启动
sudo ./xiaohuang-kylin-arm64-0.0.0.1Beta.run --dir /data/xiaohuang

# 带 Apache，HTTP 走 8080
sudo ./xiaohuang-kylin-arm64-0.0.0.1Beta.run --dir /opt/xiaohuang --with-apache --http-port 8080

# 只装 Nginx + PHP，不要数据库和 FTP（省空间）
sudo ./xiaohuang-kylin-arm64-0.0.0.1Beta.run --dir /opt/xiaohuang --no-db --no-ftp

# 装完不启动，稍后自己控制
sudo ./xiaohuang-kylin-arm64-0.0.0.1Beta.run --dir /opt/xiaohuang --no-start
```

### 3.3 全部参数

| 参数 | 作用 |
|---|---|
| `--dir <路径>` | 安装目录，默认 `/opt/xiaohuang` |
| `--http-port <端口>` | HTTP 端口 |
| `--db-port <端口>` | MySQL 端口 |
| `--ftp-port <端口>` | FTP 端口 |
| `--with-apache` | 额外装 Apache（默认只装 Nginx） |
| `--no-db` | 跳过数据库 |
| `--no-ftp` | 跳过 FTP |
| `--no-php` | 跳过 PHP |
| `--no-start` | 装完不启动 |
| `--no-link` | 不创建 `/usr/local/bin/xiaohuang` |
| `--force` | 组件起不来也继续装 |
| `--offline <目录>` | 用指定目录下的 `components/*.tar.gz` |
| `--supervisor <systemd\|pidfile>` | 服务托管方式，默认自动判断 |

### 3.4 装完你会看到

```

============================================================

  站点根目录 : /opt/xiaohuang/app/WWW
```

## 4. 第一次用

### 4.1 打开面板

面板只监听 `127.0.0.1`，本机直接开：

```
http://127.0.0.1:9002/
```

不在服务器前面？用 SSH 端口转发，比开防火墙安全得多：

```bash
# 在你自己的电脑上执行
ssh -L 9002:127.0.0.1:9002 root@你的服务器IP
# 然后本地浏览器开 http://127.0.0.1:9002/
```

### 4.2 密码忘了怎么办

```bash
sudo xiaohuang panel passwd 新密码
```

不用登录，root 直接改。改完刷新页面。

### 4.3 建第一个站点

面板「网站」→ 填域名和目录 → 添加。或者命令行：

```bash
sudo xiaohuang site add example.com /opt/xiaohuang/app/WWW/example
```

目录不存在会自动建。想先本地看效果，把域名写进 hosts：

```bash
sudo xiaohuang hosts add example.com
```

然后在浏览器访问 `http://example.com/`。

**注意**：换个域名访问需要 DNS 解析到这台机器，或者本地 hosts 指过来。只写 IP 访问的话，用默认站点（`app/WWW`）就行。

### 4.4 上 HTTPS

```bash
sudo xiaohuang site ssl example.com /path/to/cert.pem /path/to/key.pem
```

面板里点站点右边的「SSL」也能填。证书和私钥会被复制到
`app/Extensions/Nginx1.18.0/conf/ssl/`，私钥权限自动设成 600。

撤销：

```bash
sudo xiaohuang site ssl-del example.com
```

### 4.5 建数据库

```bash
sudo xiaohuang db create mydb                      # 只建库
sudo xiaohuang db create mydb myuser MyPass123     # 建库并授权
```

连上去看看：

```bash
/opt/xiaohuang/app/Extensions/MySQL10.5.23/bin/mysql \
  -uroot -proot -h127.0.0.1 -P3306 -e "show databases"
```

密码默认是 `root`。改掉：

```bash
sudo xiaohuang db passwd 新密码
```

### 4.6 建 FTP 账号

```bash
sudo xiaohuang ftp add ftp_site1 /opt/xiaohuang/app/WWW/example
```

密码留空会自动生成一个 10 位随机串，命令会打印出来。指定密码：

```bash
sudo xiaohuang ftp add ftp_site1 /opt/xiaohuang/app/WWW/example MyFtp123
```

账号是系统用户，登录后只能看见自己那个目录（chroot），拿不到别的站。

## 5. 日常操作

### 5.1 启停

```bash
sudo xiaohuang start              # 全部起（含面板）
sudo xiaohuang stop               # 全部停
sudo xiaohuang restart
sudo xiaohuang start nginx        # 只起 Nginx
sudo xiaohuang stop mysql
sudo xiaohuang status             # 看状态
```

### 5.2 Nginx 和 Apache 换着用

两个共用一个 HTTP 端口，只能同时跑一个：

```bash
sudo xiaohuang switch apache      # 切到 Apache
sudo xiaohuang switch nginx       # 切回来
```

切换会自动把开机自启也一起切过去，重启后不会变回原来那个。

### 5.3 改端口

```bash
sudo xiaohuang port nginx 8080
sudo xiaohuang port php 9100      # 会自动同步 Nginx 的 fastcgi_pass
sudo xiaohuang port mysql 3307
sudo xiaohuang ftp port 2121
```

面板「设置 → 端口」是同一套。

### 5.4 开关 PHP 扩展

```bash
sudo xiaohuang ext list
sudo xiaohuang ext enable gd
sudo xiaohuang ext disable xdebug
```

改完自动 reload php-fpm，不用手动重启。面板「PHP 扩展」是图形化的。

### 5.5 看日志

```bash
sudo xiaohuang log nginx
sudo xiaohuang log nginx -f      # 实时跟
sudo xiaohuang log php
sudo xiaohuang log mysql
sudo xiaohuang log apache
```

日志文件实际位置：`/opt/xiaohuang/logs/`、组件目录下的 `logs/`。

### 5.6 开机自启

默认 Nginx、PHP、MySQL、FTP、面板都开了：

```bash
sudo xiaohuang autostart            # 看状态
sudo xiaohuang autostart off        # 全部关掉
sudo xiaohuang autostart on
sudo xiaohuang autostart off nginx  # 只关一个
```

### 5.7 找谁占了端口

```bash
sudo xiaohuang ports
sudo xiaohuang kill --port 8080     # 不确认就直接杀掉
```

第二条命令不带确认，看清楚再敲。

## 6. 出问题了看这里

### 6.1 装不上

**退出码 2：路径不合法**

```
[FAIL] 安装路径不能包含空格: /opt/xiao huang
```

换纯英文路径。带空格、带中文都不行。

**退出码 3：路径下已有安装**

```
[FAIL] 检测到安装路径下已存在 Xiao Huang
```

要么换目录，要么先卸：`sudo xiaohuang uninstall --purge`。

**退出码 4：架构不对**

```
[FAIL] 当前架构 x86_64 不是 aarch64
```

这个包只给 arm64。x86 机器用不了。

**退出码 5：不是 root**

`sudo` 一下。

**退出码 6：组件起不来**

安装器会打印具体哪个组件失败。加 `--force` 可以装完再修，或者：
`sudo xiaohuang repair`

### 6.2 面板打不开

```bash
systemctl status xiaohuang-panel
ss -lnt | grep 9002
```

- 服务没起 → `sudo systemctl start xiaohuang-panel`
- 端口没监听 → 看日志 `journalctl -u xiaohuang-panel -n 50`
- 端口不是 9002 → `sudo xiaohuang panel url` 查真实地址

面板只监听 127.0.0.1，从别的机器直接访问是通不了的，用 SSH 转发。

### 6.3 网站 502 Bad Gateway

PHP-FPM 没跑或者端口对不上。

```bash
sudo xiaohuang status          # 看 php 是不是 running
sudo xiaohuang port php 9000   # 确认端口一致
```

端口不一致时这条命令会同时改 php-fpm 和 Nginx 的 fastcgi_pass。

### 6.4 网站 403 Forbidden

目录权限问题。目录属主必须是运行用户（一般是 www-data）：

```bash
sudo chown -R www-data:www-data /opt/xiaohuang/app/WWW/你的站
```

### 6.5 PHP 页面变成下载

Nginx 没配 PHP 解析，或者 PHP-FPM 挂了。先看 `sudo xiaohuang status`，
再 `sudo xiaohuang repair` 重建配置。

### 6.6 数据库连不上

```bash
sudo xiaohuang status
ss -lnt | grep 3306
```

- 没起 → `sudo xiaohuang start mysql`
- 起了但密码不对 → `sudo xiaohuang db passwd 新密码`
- 提示 `Can't connect to local MySQL server` → 看 `app/Extensions/MySQL10.5.23/log/error.log`

初始化失败过的，删掉数据目录重来（**会丢数据**）：

```bash
sudo systemctl stop xiaohuang-mysql
sudo rm -rf /opt/xiaohuang/app/Extensions/MySQL10.5.23/data
sudo xiaohuang repair
```

### 6.7 FTP 登录 530

- `530 Login incorrect`：密码错，或者账号不在白名单。看 `app/Extensions/FTP0.9.60/etc/userlist`
- `530 Permission denied`：账号没加白名单，重新 `xiaohuang ftp add` 一次
- 能登录但列不出目录：被动端口没放行，见 6.8

### 6.8 防火墙要开哪些端口

```bash
# firewalld
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --permanent --add-port=3306/tcp      # 只给内网的话别开
sudo firewall-cmd --permanent --add-port=21/tcp
sudo firewall-cmd --permanent --add-port=30000-30020/tcp   # FTP 被动段
sudo firewall-cmd --reload
```

FTP 被动段在 `xiaohuang.ini` 的 `FTP_PASV_MIN` / `FTP_PASV_MAX` 里查。

### 6.9 容器 / 精简系统没有 systemd

安装器会自动退回 pid 文件模式，服务用 `xiaohuang start` 管，
但没有开机自启，`xiaohuang autostart` 会直接告诉你没有这个概念。

### 6.10 端口被别的程序占了

```bash
sudo xiaohuang ports
sudo xiaohuang kill --port 8080     # 或者用 xiaohuang port nginx 8090 换个端口
```

### 6.11 想确认文件有没有被改动

```bash
sudo xiaohuang verify
```

会拿安装时的哈希清单逐个比对，列出被改过的文件。改过配置文件是正常的，
组件二进制和核心脚本被改就会报出来。

### 6.12 服务频繁重启

```bash
journalctl -u xiaohuang-nginx -n 80 --no-pager
```

`Restart=on-failure` 会在进程异常退出后 2 秒重试。连续重启说明配置有错，
先 `sudo xiaohuang repair` 重建一份，再逐项排查。

## 7. 升级和卸载

### 7.1 升级

直接装新包，安装器会保留站点和数据库：

```bash
sudo dpkg -i xiaohuang-kylin-arm64-新版本_arm64.deb
```

同路径重复安装会被拒绝（退出码 3）。跨版本升级要指定同一个 `INSTALL_DIR`：

```bash
sudo ./xiaohuang-kylin-arm64-新版本.run --dir /opt/xiaohuang
```

### 7.2 卸载

```bash
sudo xiaohuang uninstall            # 停服务、删单元，保留站点和数据库
sudo xiaohuang uninstall --purge    # 全删，包括站点和数据库
```

deb 装的：

```bash
sudo dpkg -r xiaohuang-kylin-arm64    # 保留数据
sudo dpkg -P xiaohuang-kylin-arm64    # 连配置一起删
```

### 7.3 卸载后要手动清的

- FTP 账号（系统用户）：`sudo userdel -r ftp_xxx`
- 被接管过的系统服务：`cat /opt/xiaohuang/.disabled-system-services` 里列着，需要的话 `systemctl enable` 回来
- hosts 里加过的域名：`sudo xiaohuang hosts del example.com`

## 8. 命令速查

```
# 服务
xiaohuang start|stop|restart [all|nginx|apache|php|mysql|ftp|panel]
xiaohuang status [--json]        xiaohuang info
xiaohuang switch nginx|apache    xiaohuang autostart [status|on|off] [服务]

# 站点
xiaohuang site add <域名> <目录> [端口]
xiaohuang site edit <域名> [--root 目录] [--port 端口]
xiaohuang site list [--json]     xiaohuang site del <域名>
xiaohuang site ssl <域名> <cert> <key>
xiaohuang site ssl-del <域名>

# 数据库
xiaohuang db init | passwd <密码>
xiaohuang db list | create <库> [用户 密码] | drop <库>
xiaohuang db import <file.sql> <库> | export <库> <file.sql>

# 组件
xiaohuang ext list | enable <扩展> | disable <扩展>
xiaohuang module list | enable <模块> | disable <模块>
xiaohuang version [list] | use <nginx|apache|mysql|php> <版本>

# FTP
xiaohuang ftp list
xiaohuang ftp add <账号> <目录> [密码]
xiaohuang ftp passwd <账号> <密码>
xiaohuang ftp del <账号>
xiaohuang ftp port <端口>

# 运维
xiaohuang port <服务> <端口>      xiaohuang ports
xiaohuang kill --port <端口> | --pid <pid>
xiaohuang hosts add|del <域名>
xiaohuang log <nginx|php|mysql|apache> [-f]
xiaohuang panel url | passwd <密码>
xiaohuang repair                  xiaohuang verify
xiaohuang uninstall [--purge]
```

退出码：`0` 成功、`2` 路径不合法、`3` 路径已有安装、`4` 架构不符、`5` 非 root、`6` 组件失败、`7` 启动失败。
